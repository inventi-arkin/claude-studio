Claude Code, in a friendly window.

Claude Studio is a local web UI for Claude Code on Windows. Chats by project, clear permission cards, a pixel companion, and it all runs only on your PC.

What it does

💬 Chats by project

Every chat belongs to a project folder or General; pick up any chat later, even after closing the tab.

🛡 Clear permissions

Readable cards for each action, with Allow, and Always allow for this chat, this project or everywhere.

🔔 Away status

Leave a long task running; Studio tells you when it's done or needs you.

🐾 Companions and places

A pixel companion keeps you company. Describe your own creature or place and Claude draws it.

⌨ Command console

Claude Code's slash commands, with help, in a palette.

⬆ Updates

Studio checks this site and installs new versions in one click, going back by itself if one doesn't start.

Install

  • Windows 10 or 11
  • A Claude account (Pro, Max, Team or Enterprise), or an API key
  • Node.js, Git and Claude Code: the installer offers to install them
  • About 300 MB of disk space
  1. Download the zip above and unzip it anywhere (for example Downloads).
  2. Double-click "Install Claude Studio.cmd". It checks what's missing, offers to install it, and asks you to sign in to Claude if needed.
  3. Open "Claude Studio" from the desktop shortcut. It runs at http://localhost:4300, only on this PC.

⚠ Windows may say "Windows protected your PC" the first time, because the installer isn't signed by a publisher. Choose More info → Run anyway if you downloaded it from this page.

Privacy

Claude Studio runs on your PC and only listens to your own browser. Your chats, files and settings never leave the PC, except what Claude Code itself sends to Anthropic to answer you.

To check for updates, Studio reads two small files from this site (when it starts, every 6 hours, or when you click Check for updates; you can turn the automatic check off). It sends nothing about you or your PC. Updates are signed, and nothing is installed unless you click Update.

Downloads. Opening this page loads nothing from other sites. The Download button fetches the zip from GitHub, which counts downloads and, like any download site, may log your IP address. Once installed, Studio contacts only this website, and only to check for updates.

Claude Studio is a personal, unofficial project. Claude and Claude Code are products of Anthropic.
